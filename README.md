# Rojo Aburrá · Discografía

Reproductor web de los álbumes instrumentales de **Rojo Aburrá** (Medellín):

- **Eternal Spring**: el día en el Valle de Aburrá, jazz y lo-fi.
- **Concrete Valley**: la noche en Medellín, boom bap pesado.
- **Olium**: el petróleo como metáfora, boom bap duro y oscuro.
- **Sputnik**: la carrera espacial soviética, boom bap con 808, coros y metales.

Se puede escuchar desde el navegador del celular o del PC, con controles en la pantalla bloqueada,
y se puede instalar como app desde el navegador ("Agregar a pantalla de inicio").

Música compuesta y producida con inteligencia artificial (Claude) para Rojo Aburrá. Portadas: Rojo Aburrá.
